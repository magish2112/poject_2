Проект: Серверная часть медицинской платформы (аналог Fullscript) на FastAPI

---

1. Краткое описание текущего статуса

- Реализована серверная часть (backend) проекта на FastAPI.
- Проект структурирован по современным best practices (модули: пользователи, аутентификация, курсы лечения, аптека, покупки, отчёты и др.).
- Все основные REST API реализованы: регистрация, логин, CRUD для пользователей, курсов, назначений, покупок, заказов в аптеке.
- Используются заглушки вместо реальной базы данных — это позволяет демонстрировать и тестировать API без запуска БД.
- JWT-авторизация (заглушка), поддержка ролей (врач, пациент, админ), ограничения доступа к эндпоинтам.
- Swagger UI для тестирования и демонстрации API (http://127.0.0.1:8000/docs).
- Встроенная админ-панель на SqlAdmin для ручного управления всеми моделями (http://127.0.0.1:8000/admin).
- Проект готов к переходу на реальную работу с базой данных (SQLModel + Alembic миграции).
