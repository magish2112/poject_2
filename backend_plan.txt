Пошаговый план создания серверной части сайта (аналог fullscript.com)
===============================================================

1. Анализ требований и постановка задачи
----------------------------------------
- Изучить логику работы fullscript.com, определить ключевые функции для MVP:
  - Регистрация/авторизация врачей и пациентов
  - Назначение курсов лечения врачом
  - Просмотр назначений пациентом
  - Интеграция с внешней аптекой по API для покупки препаратов
  - Контроль и корректировка курсов лечения врачом
- Составить user stories для каждого типа пользователя

2. Проектирование архитектуры
-----------------------------
- Выбрать стек технологий (например: Python + FastAPI, PostgreSQL, JWT)
- Определить архитектурный паттерн (Clean Architecture/Onion/Hexagonal)
- Нарисовать схему основных сущностей и их связей (ER-диаграмму)
- Определить основные модули и слои приложения

3. Проектирование базы данных
-----------------------------
- Описать основные модели:
  - User (Doctor, Patient)
  - TreatmentPlan (Курс лечения)
  - Medication (Препарат)
  - Prescription (Назначение)
  - Purchase (Покупка)
- Продумать связи между моделями (one-to-many, many-to-many)
- Составить миграции для создания таблиц

4. Проектирование API
---------------------
- Описать основные эндпоинты для врачей и пациентов
- Описать эндпоинты для интеграции с аптекой
- Продумать структуру запросов и ответов (JSON-схемы)
- Определить механизмы аутентификации и авторизации (JWT)

5. Настройка окружения и инфраструктуры
---------------------------------------
- Инициализировать репозиторий (git)
- Настроить виртуальное окружение/зависимости (requirements.txt или pyproject.toml)
- Настроить базу данных (PostgreSQL)
- Настроить переменные окружения (dotenv)

6. Реализация моделей и миграций
-------------------------------
- Реализовать модели данных (ORM)
- Написать миграции и применить их к базе

7. Реализация бизнес-логики (сервисный слой)
--------------------------------------------
- Реализовать сервисы для работы с пользователями, курсами лечения, назначениями, покупками
- Реализовать интеграцию с внешней аптекой (REST API)

8. Реализация API (контроллеры)
-------------------------------
- Реализовать эндпоинты для врачей (создание/редактирование курсов, назначений)
- Реализовать эндпоинты для пациентов (просмотр, покупка, отчеты)
- Реализовать эндпоинты для интеграции с аптекой

9. Реализация аутентификации и авторизации
------------------------------------------
- Реализовать регистрацию и вход (JWT)
- Ограничить доступ к эндпоинтам по ролям

10. Тестирование
----------------
- Написать unit-тесты для бизнес-логики
- Написать интеграционные тесты для API
- Протестировать интеграцию с аптекой (mock/external)

11. Документирование API
-----------------------
- Описать API с помощью OpenAPI/Swagger
- Подготовить README с инструкциями по запуску

12. Развертывание и запуск
-------------------------
- Настроить docker-compose для локального запуска
- Подготовить скрипты для деплоя (например, на VPS или облако)
- Провести smoke-тесты на проде

13. Поддержка и доработка
------------------------
- Собирать обратную связь
- Исправлять баги, дорабатывать функционал
